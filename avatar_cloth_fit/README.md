# Avatar Cloth Fit

An offline Blender extension for shaping avatar clothing by hand and
transferring and refining its skin weights. Requires Blender 5.0 or newer.

Tools include Smart Grab, Fit to Body, Shape Relax, Region Resize, Adjust
Region, pose-guided weight refinement, and clothing armature creation.

## Install

Download `avatar_cloth_fit-1.8.4.zip` from the
[latest release](https://github.com/Peppxrr/avatar-cloth-fit/releases/latest).
In Blender, open **Edit → Preferences → Get Extensions → menu → Install from Disk**
and select the ZIP without extracting it. Open **3D Viewport → N → Cloth Fit**.

## Documentation

See [USER_GUIDE.md](USER_GUIDE.md) for setup, controls, settings and troubleshooting.
The guide is also included in the install ZIP.

[Project and source](https://github.com/Peppxrr/avatar-cloth-fit) ·
[Report a problem](https://github.com/Peppxrr/avatar-cloth-fit/issues)

Clothing needs a reasonable starting shape. Inspect the fit in poses and in
your target application; complex garments may still need manual mesh edits.
